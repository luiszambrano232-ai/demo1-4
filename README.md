# Zurieth Arias — Estética & bienestar

Landing page estática preparada para GitHub Pages.

## Publicar

1. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets` a la raíz del repositorio.
2. En GitHub abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.

## Configurar WhatsApp

Abre `script.js` y reemplaza el valor vacío de `whatsappNumber` por el número real con código de país, sin `+`, espacios ni guiones. Ejemplo: `56912345678`.

Los valores, promociones, horarios y textos son referenciales y deben confirmarse con la clienta antes de publicar la versión final.
